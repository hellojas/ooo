## Decisions taken
- Core stack: Kaufman Tue + Thu, Barry Harris Sundays ($100), NYJW Standards
  on flex. Pending: BKCM Piano Lab. Optional: NYJW Songbook Wed, BH free Tue.
- Skip 92NY Keyboard (too beginner, clash) and 92NY Improv (half over).
- CoRL: go — costs one $15 Sunday and a flex Saturday.
- Taipei: leave Dec 16 or later; only Blues Jam Dec 17 is lost. Winter
  intensives only work if Taipei moves earlier and Dec 28 is taken off.
- Kaufman commutes are the longest (~45 min each way); worth it for content.

## Online options considered

  arrangement-block curriculum for wk 4–10 if bought. Skip the 1:1 coaching.
- Learn Jazz Standards: general, overlaps Open Studio + classes. Skip.
- NYJW online "Ear Training for Musicians" — only structured ear option tied
